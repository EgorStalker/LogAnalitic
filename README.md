# LogAnalitic 📊⚙️

Високопродуктивний програмний комплекс для автоматизованого парсингу, обробки та глибокого аналізу великих масивів системних логів. Проєкт розроблений для роботи з неструктурованими даними великого обсягу (успішно апробовано на датасеті розподіленої системи HDFS обсягом понад 13 мільйонів рядків).

> 🏆 Нагорода: Проєкт посів II місце на національному етапі конкурсу ISEF Ukraine 2026.

---

## 🚀 Основні можливості

- Пакетна (Chunk-based) обробка: Дозволяє опрацьовувати величезні файли (у десятки гігабайтів) зі стабільно низьким споживанням оперативної пам'яті.
- Інтелектуальна нормалізація: Автоматичне розпізнавання та заміна змінних ідентифікаторів (IP-адрес, GUID, системних хешів) універсальними маркерами для усунення «семантичного розриву».
- Синтаксичний парсинг: Швидке виділення часових міток, рівнів серйозності (log levels) та системних компонентів.
- Статистична агрегація та візуалізація: Генерація звітів, часових графіків і гістограм для оперативного виявлення аномалій та збоїв у роботі систем.
